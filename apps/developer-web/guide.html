写一个真正可安装的应用

1. 创建应用目录

包含 manifest.json、index.html 和 assets/icon.png。入口内使用宿主注入的 Simulator SDK，不需要引入 sdk.js。

{
 "schemaVersion": 1, "id": "com.example.notes",
 "name": "我的笔记", "version": "1.0.0",
 "runtime": "web", "entry": "index.html",
 "permissions": ["storage"], "orientation": "portrait",
 "icon": "assets/icon.png"
}

2. 使用 SDK 保存数据

await Simulator.storage.set('note', 'Hello iOS 6');
const note = await Simulator.storage.get('note');
await Simulator.ui.alert('保存成功');

3. 打包与测试

python packages/simapp-cli/simapp.py pack examples/pixel-notes -o PixelNotes.simapp

Connect 创建应用 → 上传 → 创建测试组 → 生成邀请码。测试者在 Beta 中兑换邀请码、安装和提交反馈。

4. 审核与发布

提交审核后由独立审核员处理。审核通过后，开发者点击正式发布，商店才会展示应用。相同版本不可重复上传，更新请增加版本号。

运行时边界

默认不允许外部网络、框架、摄像头或任意文件访问。iOS 支持多文件本地资源；网页预览仅支持内联 HTML/CSS/JS。卸载删除私有数据，更新保留数据。Beta 到期后下载与反馈权限失效，已下载网页包不支持远程擦除。
