# 素材来源

- 示例应用图标：本项目程序生成的原创渐变、笔记线条与圆环。
- 桌面与锁屏壁纸：`ios6-wallpaper.png` / `wallpaper.png`，来自 [draenkov/Wallpapers](https://github.com/draenkov/Wallpapers) 归档的 `iPhone/4.0"/iOS 6/Stills/100-568h@2x~iphone.png`。原文件为 Apple CgBI PNG，仅转换编码和通道顺序以支持现代浏览器，画面未重绘。
- 系统图标：备忘录、计算器、设置及 App Store 的 JPG 来自 [zagnut531/iOS-6-Icons](https://github.com/zagnut531/iOS-6-Icons) 的 `iPhone & iPod touch/Cropped icons`，由旧设备图标导出。原始作品与商标权归各自权利人；归档没有授予本项目独立的再分发或商业许可。公开发布及商业使用前应取得相应授权。
- Beta 测试图标：本项目代码绘制的蓝色渐变与飞机符号。iOS 6 时代没有对应的系统 TestFlight 图标。
- 其余拟物化界面：本项目 CSS / Core Animation 绘制。
- ZIPFoundation：Swift Package Manager 拉取的第三方依赖，版本 0.9.19；许可证与安全公告由上游仓库提供。
- “iOS 6”用于说明设计方向；宿主名为 Retro6，界面明确标示独立生态。
