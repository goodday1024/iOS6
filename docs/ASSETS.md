# 素材来源

- 示例应用图标：本项目程序生成的原创渐变、笔记线条与圆环。
- 背景与拟物化界面：本项目 CSS / Core Animation 绘制的原创渐变，不包含提取自 iOS 固件的图标、壁纸或声音。
- 原生系统图标：系统 SF Symbols，通过 UIKit UIImage(systemName:) 调用，受 Apple 对系统符号的使用规定约束，不作为独立素材分发。
- ZIPFoundation：Swift Package Manager 拉取的第三方依赖，版本 0.9.19；许可证与安全公告由上游仓库提供。
- “iOS 6”用于说明设计方向；宿主名为 Retro6，界面明确标示独立生态。
